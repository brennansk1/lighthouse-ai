## 2. Architectural Principles (enforced during this sweep)

These are extracted from the existing codebase, not invented; the sweep conforms to them.

1. **Sync-first.** The codebase is deliberately synchronous (3 `async def` total, all SSE in `web/routes.py`). No new asyncio in core logic.
2. **httpx only**, always through `net.guarded_get` with an explicit domain allowlist. No raw `httpx.get`, ever `requests`.
3. **Frozen dataclasses** for config/results; Pydantic confined to `web/api.py` (FastAPI boundary). Don't migrate either direction.
4. **structlog everywhere**, context-kwarg style (`log.info("event", key=value)`). No stdlib `logging`.
5. **Domain exceptions + graceful degradation.** Optional heavy deps are lazy-imported; absence degrades (e.g., `RerankerUnavailable` → passthrough), never crashes.
6. **Duplication in `skills/library/` and `sources/` is intentional.** Each skill/source is an isolated, vetted primitive behind the import guard. *Do NOT introduce a shared base class across skills* — it would couple sandboxed units and enlarge the guard surface.
7. **Local-first is the product.** No feature may add a cloud dependency or a default network call. Every new fetch path goes through egress enforcement and the audit log.
8. **Simple UX is a feature.** Customer is a researcher in a regulated setting (legal/clinical/financial), not a developer. New surfaces must be: one CLI verb or one dashboard element, zero-config defaults, plain language. No new tabs, no settings sprawl, no multi-step wizards.
